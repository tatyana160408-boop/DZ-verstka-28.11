# DZ — вёрстка 28.11

Адаптивная страница вакансии «Специалист по дизайну цифровых музеев» по макету Figma.

HTML и CSS, без JavaScript и сборщиков. Меню на телефоне работает через details/summary.

## Как открыть

Скачайте проект и откройте index.html в браузере. Для загрузки Geist и Manrope через Google Fonts нужен интернет.

## Структура

- index.html — общая разметка для ноутбука и телефона;
- assets/images/ — логотипы из макета;
- assets/styles/fonts.css — подключение Google Fonts;
- assets/styles/reset.css — сброс стилей;
- assets/styles/layout.css — оформление и адаптив;
- assets/styles/style.css — подключение CSS и общие цвета.

У кнопок без заданного адреса нет обработчиков и выдуманных ссылок.
